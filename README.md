# Вектор.Генератор заданий

Система автоматизированной генерации персонализированных учебных заданий на основе анализа результатов обучения. Проект разработан в рамках выпускной квалификационной работы и демонстрирует подход к адаптивному обучению с использованием современных технологий анализа данных и генерации текста.

---

## 📌 Описание проекта

Система предназначена для формирования учебных заданий, адаптированных под уровень знаний конкретного обучающегося. В основе лежит анализ истории выполнения заданий, определение слабых тем и динамики прогресса, после чего генерируются новые задания с учётом этих данных.

Решение ориентировано на снижение нагрузки на преподавателей и повышение эффективности обучения за счёт персонализации контента.

---

## ⚙️ Основной функционал

* Анализ образовательных данных обучающегося
* Отслеживание прогресса и динамики результатов
* Определение уровня подготовки и слабых тем
* Генерация персонализированных заданий с использованием LLM
* Адаптация сложности заданий
* Сохранение истории выполнения заданий
* Интерфейс обучающегося
* Интерфейс преподавателя
* Панель сотрудника организации (аналитика)
* Панель администратора (управление пользователями)

---

## 🏗 Архитектура системы

Система построена по модульному принципу и включает следующие компоненты:

### Backend

* `task_generator.py` — генерация заданий
* `progress_tracker.py` — анализ прогресса
* `profile_analyzer.py` — анализ профиля обучающегося
* `auth/` — аутентификация и управление доступом
* `database/` — работа с базой данных (ORM + менеджер запросов)

### Frontend

* `pages/` — пользовательский интерфейс (Streamlit)

  * панель студента
  * панель преподавателя
  * панель администратора
  * панель организации

### База данных

* `database/` — пользовательский интерфейс (Streamlit)
* `models.py` — описание структуры данных
* `db_manager.py` — централизованная работа с БД

## 🚀 Запуск проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/elizavetakurganova/VectorPersonalizedTasks
cd VectorPersonalizedTasks
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка конфигурации

Указать параметры подключения к базе данных в `config.py`.

### 4. Инициализация базы данных

```bash
python -c "from database.models import init_db; init_db()"
```

### 5. Запуск приложения

```bash
streamlit run app.py
```
